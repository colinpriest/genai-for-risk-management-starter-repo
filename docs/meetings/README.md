# Meeting records go here

**Separate files per meeting**, named so the completeness check can pair them — for a
meeting on 16 March 2026:

```
2026-03-16-transcript.md
2026-03-16-minutes.md
```

A combined file holding both halves does **not** pass: the check requires a transcript and
minutes for every date it finds. At least two dated meetings, each fully paired.

**Or** submit identifiable records to the restricted Moodle item instead and declare that
route by replacing this file's contents with a line of exactly this form, with the
placeholder filled in:

```
SUBMISSION ROUTE: <Moodle or repository>
```

Write the real word in place of the placeholder. This file as shipped declares nothing -
the check reads it as the template it is, not as your team's statement.

See `../README.md` and, on Moodle, `team-templates/meeting-records-requirements.md`.
